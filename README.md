# SOC Investigation Write-ups

Short, structured walkthroughs of security investigations I complete in training platforms (TryHackMe, Blue Team Labs Online, LetsDefend, etc.). Each write-up shows how I think through an alert, not just which tool I clicked.

## Write-up template
Every case follows the same format:
1. **Scenario**: what the alert or task was
2. **Evidence reviewed**: logs, endpoints, network data
3. **Analysis**: what I found and how I reasoned about it
4. **MITRE ATT&CK mapping**: tactics and techniques observed
5. **Verdict & response**: true/false positive, containment and next steps
6. **Lessons learned**
